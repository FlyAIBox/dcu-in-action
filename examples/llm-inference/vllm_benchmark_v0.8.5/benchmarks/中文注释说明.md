### 2. 性能指标详解
```python
# ==================== 关键性能指标说明 ====================
# TTFT (Time To First Token): 首个token生成时间，反映模型响应速度
# TPOT (Time Per Output Token): 平均每个输出token的生成时间
# ITL (Inter-Token Latency): token间延迟，反映生成流畅度
# E2EL (End-to-End Latency): 端到端延迟，完整请求处理时间
```
