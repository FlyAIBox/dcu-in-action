# vLLM基准测试配置文件使用指南

## 📋 概述

本目录包含了7个详细注释的YAML配置文件，涵盖了vLLM基准测试的各种场景。每个配置文件都包含了完整的中文注释，解释了参数的含义、使用场景和最佳实践。

## 📁 配置文件列表

### 1. `serving_test.yaml` - 在线服务基准测试
**适用场景**: 评估vLLM在线API服务的性能
- ✅ 使用ShareGPT真实对话数据
- ✅ 中等负载测试 (2 req/s)
- ✅ 适合生产环境性能评估

**关键配置**:
```yaml
model: meta-llama/Llama-2-7b-hf
backend: vllm
dataset_name: sharegpt
request_rate: 2.0
num_prompts: 100
```

### 2. `throughput_test.yaml` - 离线吞吐量测试
**适用场景**: 测试模型的最大处理能力
- ✅ 使用随机数据消除变量影响
- ✅ 大批量请求 (1000个)
- ✅ 适合容量规划和性能基准

**关键配置**:
```yaml

output_len: 128
tensor_parallel_size: 1
```

### 3. `vision_test.yaml` - 视觉语言模型测试

- ✅ 使用VisionArena视觉对话数据

**关键配置**:

## 🚀 快速开始

### 1. 基础使用
```bash
# 使用配置文件运行测试
python enhanced_benchmark_serving.py --config benchmark_configs/serving_test.yaml

# 覆盖配置文件中的参数
python enhanced_benchmark_serving.py \
    --config benchmark_configs/serving_test.yaml \
    --num-prompts 200 \
    --request-rate 5.0
```

### 2. 批量测试
```bash
# 运行多个配置文件进行对比
for config in serving_test throughput_test stress_test; do
    python enhanced_benchmark_serving.py \
        --config benchmark_configs/${config}.yaml \
        --result-dir ./results/${config}
done
```

### 3. 自定义配置
```bash
# 复制现有配置文件并修改
cp benchmark_configs/serving_test.yaml my_custom_test.yaml
# 编辑 my_custom_test.yaml
python enhanced_benchmark_serving.py --config my_custom_test.yaml
```

## 📊 配置参数详解

### 核心参数分类

#### 模型配置
- `model`: 模型名称或路径
- `backend`: 推理后端 (vllm, openai, tgi)
- `endpoint`: API端点路径
- `max_model_len`: 最大序列长度

#### 数据集配置
- `dataset_name`: 数据集类型
- `dataset_path`: 数据集路径
- `num_prompts`: 测试请求数量
- `input_len/output_len`: 序列长度

#### 性能配置
- `request_rate`: 请求发送速率
- `tensor_parallel_size`: 张量并行度
- `temperature/top_p`: 采样参数

#### 输出配置
- `save_result`: 是否保存结果
- `enable_visualization`: 是否生成图表
- `result_dir`: 结果保存目录

## 📈 结果分析指南

### 关键指标解读
- **TTFT (首Token时间)**: 响应速度指标
- **TPOT (每Token时间)**: 生成效率指标
- **吞吐量**: 整体处理能力指标
- **成功率**: 系统稳定性指标

### 性能优化方向
1. **延迟优化**: 降低TTFT，提升用户体验
2. **吞吐量优化**: 提高并发处理能力
3. **资源优化**: 平衡性能和成本
4. **稳定性优化**: 确保高可用性

## 🛠️ 故障排查

### 常见问题
1. **OOM错误**: 减少batch_size或序列长度
2. **连接超时**: 检查服务状态和网络
3. **数据集错误**: 确认数据集路径和格式
4. **配置冲突**: 检查参数兼容性

### 调试技巧
- 使用小规模测试验证配置
- 检查vLLM服务日志
- 监控系统资源使用
- 逐步增加负载测试
